# c-shomework

C++ 课程练习合集：4 个独立小程序 + 1 个多文件综合程序（校园一卡通消费管理系统）。覆盖**结构体、C 风格字符串与指针、内联函数 / 默认参数 / 函数重载、引用传参、动态内存与异常处理**。

## 文件一览

| 文件 | 主题 | 说明 |
| --- | --- | --- |
| `Untitled-1.cpp` | 结构体 + 格式化输出 | 读入 n 个学生的姓名、语文、数学、英语成绩，对齐输出三科成绩与平均分；平均分 ≥ 90 的行末追加 `Excellent` |
| `Untitled-2.cpp` | 字符指针遍历 | `countVowels(const char*)` 用指针逐字符扫描，统计元音字母（a e i o u，大小写都算）个数 |
| `Untitled-3.cpp` | 内联函数 / 默认参数 / 重载 | `square()` 求平方；`power()` 幂运算（指数默认 3）；`calc()` 四则运算（含除零保护）；`calc()` 同时有 `double` 与 `int` 两个重载版本 |
| `Untitled-4.cpp` | 引用传参 | `swap(int&, int&)` 交换两个整数，打印交换前后结果 |
| `card1.cpp` | 头文件（接口声明） | 一卡通系统的声明：`Card` 结构体、`card` 命名空间、动态数组 / 充值 / 消费 / 查询 / 报表的函数原型。**内容实际是头文件 `card_operations.h`**（带 include guard），编译前需改名 |
| `card2.cpp` | 模块实现 | 一卡通系统全部函数实现：`new(nothrow)` 动态数组、`deposit` / `spend` 重载、`const` 引用与 `const` 指针查询、`static_cast` 元转分、报表打印 |
| `card3.cpp` | 主程序 | `main()`：读账户数量与信息 → 充值 100 元 → 消费 8.5 元 → 查余额 / 学号 → 打印全部报表；用 `try/catch` 处理 `bad_alloc` 与 `runtime_error` |

## 编译与运行

```bash
g++ -std=c++11 -O2 Untitled-1.cpp -o u1 && ./u1
```

> 备注：这几个文件最初的缩进是不间断空格（U+00A0，在 VSCode 里看着和普通空格一样，但 `g++` 会报
> `error: stray '\302' in program`），已在提交 “Normalize indentation” 中统一改成普通空格，代码逻辑未改动。

### 一卡通系统（card1 ~ card3）

`card1.cpp` 里是头文件内容（`card_operations.h`），先复制成同名头文件再一起编译：

```bash
cp card1.cpp card_operations.h
g++ -std=c++11 -Wall card2.cpp card3.cpp -o card_system
./card_system
```

## 运行示例

### Untitled-1.cpp —— 学生成绩表

输入：

```text
3
Zhang 90 80 70
Li 95 96 97
Wang 60 70 80
```

输出（姓名后补齐到 8 列，成绩保留两位小数）：

```text
Zhang   90.00   80.00   70.00   80.00
Li      95.00   96.00   97.00   96.00    Excellent
Wang    60.00   70.00   80.00   70.00
```

### Untitled-2.cpp —— 统计元音

输入 `Hello World` → 输出 `Number of vowels: 3`

### Untitled-3.cpp —— 函数练习

输入 `5 3 +`：

```text
square(5) = 25.00
power(5,3) = 125.00
5 + 3 = 8.00
```

除零输入 `5 0 /` 时，第三行改为 `Error: divide by zero`。

### Untitled-4.cpp —— 引用交换

输入 `10 20`：

```text
Before swap: x=10, y=20
After  swap: x=20, y=10
```

### card1 ~ card3 —— 校园一卡通消费管理系统

输入 2 个学生账户：`2024001 Zhang 50.5`、`2024002 Li 120`。程序对第一个账户充值 100 元（扣 2% 手续费，实到 98 元），再消费 8.5 元，余额 `50.5 + 98 - 8.5 = 140.00`：

```text
============================================================
          校园一卡通消费管理系统
============================================================
请输入学生账户数量：请输入第1个学生【学号 姓名 初始余额】：请输入第2个学生【学号 姓名 初始余额】：

===== 对第一个账户充值100元 =====

===== 消费：食堂午餐 8.5元 =====
消费项目：食堂午餐

===== 查询第一个账户信息 =====
账户余额：140.00 元
学生学号：2024001
当前余额换算成分：14000 分

===== 全部账户报表 =====
------------------------------------------------------------
ID        Name           Balance(元)Transactions
------------------------------------------------------------
2024001   Zhang          140.00      2
2024002   Li             120.00      0
------------------------------------------------------------

内存释放完成，系统退出。
```

> 说明：程序末尾有 `system("pause")`，是 Windows 下的写法；在 Linux/macOS 上可删掉该行。
